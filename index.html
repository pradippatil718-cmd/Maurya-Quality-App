Data Export

सर्व (आतापर्यंतच्या सगळ्या दिवसांचे) entries एका Excel-compatible CSV फाईलमध्ये export होतील — ती फाईल Excel मध्ये थेट उघडता येते. पूर्ण automatic (न दाबता) file update होणे शक्य नाही, कारण ब्राउझर सुरक्षा कारणासाठी थेट डिस्कवर automatic लिहू देत नाही — त्यासाठी सशुल्क सर्व्हर लागतो. म्हणून रोज शेवटी हे बटण दाबून ताजी फाईल डाउनलोड करा.

जुनी/Updated Excel मधून Latest Data घ्या

तुमची Excel file आधी CSV म्हणून Save करा (Excel मध्ये: File → Save As → CSV UTF-8). मग ती इथे upload करा — जुन्या नोंदी (matching ID असल्यास) update होतील आणि नवीन नोंदी add होतील. काहीही डिलीट होणार नाही.

PC च्या Local Folder मध्ये Auto-Save (फक्त Desktop Chrome/Edge)

हे फक्त desktop च्या Chrome/Edge browser मध्ये चालते, phone वर नाही. एकदा एक file location निवडा — मग ही tab उघडी असेपर्यंत दर काही मिनिटांनी ती file आपोआप ताज्या data ने update होत राहील. Tab बंद केल्यावर पुन्हा उघडल्यावर एकदा पुन्हा "Link" करावं लागेल (browser च्या सुरक्षा नियमांमुळे).

⚙️ पहिल्यांदा Setup करा (एकदाच)

सर्व users वर same data दिसण्यासाठी एक free Firebase database लागतो. फक्त एकदाच ही पायरी करा:

  1. console.firebase.google.com वर जा, Google account ने login करा.
  2. "Add project" दाबून नवीन project बनवा (कोणतंही नाव चालेल, Google Analytics नको).
  3. डाव्या मेनूत Build → Realtime Database उघडा → "Create Database" → location निवडा → "Start in test mode" निवडा.
  4. वर दिसणारा Database URL कॉपी करा (उदा. https://xxxx-default-rtdb.firebaseio.com).
  5. ही HTML file कोणत्याही text editor मध्ये उघडा, FIREBASE_DB_URL शोधा, तिथे तुमचा URL paste करा, save करा.
  6. ही updated file सर्व inspectors च्या phones वर पाठवा (WhatsApp/Drive ने).

हे पूर्ण मोफत आहे (Firebase Spark plan), credit card लागत नाही. मदत हवी असल्यास Database URL मला द्या, मी file तयार करून देतो.
